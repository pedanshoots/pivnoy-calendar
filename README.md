# Пивной календарь — GitHub Pages v8

Статическая версия без PHP: её можно публиковать через GitHub Pages.

Что работает:
- мобильный интерфейс и PWA;
- выбор даты;
- пиво / виски / чай с бергамотом;
- ссылка-приглашение для Рафа;
- сравнение даты и напитка;
- ссылка на готовый результат;
- анимации и фотографии.

Важно: GitHub Pages не хранит общий серверный state. Поэтому в этой версии синхронизация реализована через параметры ссылки: Раф получает выбор Ильи в ссылке, после своего ответа формируется ссылка с обоими выборами, которую можно отправить Илье. Для настоящего автоматического обновления у двух телефонов нужен внешний backend (например Supabase/Firebase).
