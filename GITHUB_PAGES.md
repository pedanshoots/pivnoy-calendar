# Публикация через GitHub Pages

1. Создай новый публичный репозиторий, например `pivnoy-calendar`.
2. Загрузи в него ВСЁ содержимое этой папки (`index.html`, `manifest.webmanifest`, `sw.js`, `assets/`).
3. GitHub → Settings → Pages.
4. В Source выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`.
6. Сохрани. GitHub выдаст адрес вида `https://ТВОЙ-ЛОГИН.github.io/pivnoy-calendar/`.

PHP и папка `data/` больше не нужны.
